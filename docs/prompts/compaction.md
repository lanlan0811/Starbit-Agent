# 压缩摘要模板

上下文即将达到上限，请对近期的会话产生结构化摘要，用于在压缩后重建上下文。摘要应简洁、聚焦，可直接作为后续巡航的上下文锚点。

## 摘要格式

```markdown
## 目标
（用户当前要完成的核心目标；若有多个，编号列出）

## 已完成
- 已完成的步骤与结果（关键产出、文件路径）

## 未完成 / 进行中
- 下一步要做什么，依赖哪些已完成内容

## 关键文件
- 重要的文件路径及其作用（代码/文档/配置）

## 坑与注意事项
- 踩过的坑、需要记住的约束、待确认事项
```

## 要求

- 只包含可复现的事实与路径，不包含过度的主观描述。
- 保留所有仍有效的关键上下文（变量、约定、进行中任务）。
- 压缩后需保持输入确定（temperature=0）以保证重压缩一致性（§3.6 规则 7）。
