## 触发方式

1. **渐进披露**：系统提示只注入技能索引（name+description）；当任务与某个技能描述匹配时，将该技能的 SKILL.md 正文作为该轮上下文注入。
2. **斜杠命令**：用户在输入框以 `/技能名` 直接触发。
3. **带脚本技能包**：技能若带脚本，脚本作为受限工具暴露，执行需经权限门控。

## 编写规范

兼容 Claude Skills 格式（`SKILL.md` + frontmatter）：

```yaml
---
name: skill-name
description: 技能用途（用于渐进披露匹配）
---
```

- `name` 唯一，用作斜杠命令与脚本命名空间。
- `description` 精炼、面向触发匹配，说明“何时用”。
- 正文为 Markdown，描述技能的工作流、脚本、注意事项。

## 规则

- 同一技能重复加载复用首次注入的文本（§3.6 规则 3，只追加、不回插）。
- 技能注入不改变工具列表或系统前缀（保持缓存稳定）。
