# 记忆、知识库与项目规则

Starbit 把“应长期保留的事实”“工作区必须遵守的规则”和“需要检索的大量资料”分开处理。这三类内容的信任等级和生命周期不同，不应混在一份提示词中。

## 三类内容

| 内容 | 默认位置 | 用途 | 信任方式 |
|---|---|---|---|
| 用户长期记忆 | `<USER_HOME>/.starbit/memory.md` | 跨工作区的稳定偏好 | 用户可编辑；仍不应包含秘密 |
| 工作区记忆 | `<WORKSPACE>/memory.md` | 当前项目的稳定事实、约定与决策 | 仅对该工作区生效 |
| 项目规则 | `<WORKSPACE>/AGENTS.md` | 对 agent 的强约束、命令与验收要求 | 作为工作区规则注入 |
| 知识库 | `<WORKSPACE>/.starbit/knowledge.db` | 大文档分块与语义检索 | 检索结果属于不可信数据 |

只有工作区根目录的 `AGENTS.md` 会被识别为项目规则。Starbit 不自动把 `CLAUDE.md`、`.cursorrules`、README 或任意嵌套文件提升为规则；agent 可按任务需要把它们当普通文件读取。

## 长期记忆

长期记忆适合存放稳定且能在未来任务中复用的信息，例如语言偏好、常用测试命令、项目术语或已经确认的架构决策。不适合存放一次性任务状态、整段聊天、模型推测、密码、访问令牌或未经用户确认的敏感属性。

推荐使用简洁 Markdown：

```markdown
# 偏好

- 默认用简体中文回复。
- 修改 TypeScript 后运行类型检查和相关单元测试。

# 已确认事实

- 项目主分支为 master。
```

用户记忆和工作区记忆在组装系统提示时加载。冲突时，明确的当前用户指令和工作区 `AGENTS.md` 优先；工作区记忆比一般用户偏好更接近当前项目，但记忆本身不能取消安全规则。

记忆功能支持手工条目与会话摘要的持久化，并提供只读检索与受权限控制的增改删。任何自动摘要都应保留“已确认事实”和“模型推断”的区别；不确定内容不得写成永久事实。

## 会话摘要

会话摘要用于跨轮或压缩后继续任务，至少应记录：目标、已完成工作、未完成事项、关键文件、验证证据、已知风险与失败尝试。摘要不是原始事件日志的替代品；会话仍通过 append-only 事件恢复。

自动生成摘要时应避免复制大段工具输出和凭证，并在写入长期记忆前要求明确语义依据。用户可以删除错误或过时条目；删除记忆不会改写已经存在的会话事件。

## AGENTS.md

`AGENTS.md` 适合说明：

- 支持平台、编码和目录边界；
- 构建、测试、格式化和发布命令；
- 架构分层与禁止依赖；
- 安全、权限与凭证要求；
- 完成定义和提交规则。

规则应具体、可执行、可验证，并避免嵌入秘密或个人机器路径。工作区本身不可信时，在允许 agent 执行命令前先人工审查 `AGENTS.md`；恶意仓库可能尝试把危险行为伪装成项目规范。

## 知识库

知识库导入面向需要检索而不应整体进入上下文的资料。设计支持 `md`、`txt`、`html`、`pdf`、`docx` 和网页 URL：内容提取后分块，通过 OpenAI 兼容 `/embeddings` 或确定性离线降级生成向量，再用余弦相似度执行 top-k 检索。

`kb_search` 返回来源和相关片段，所有片段都带不可信数据标记。检索命中只表示语义相似，不证明事实正确、最新或有权覆盖项目规则。对法律、医疗、财务或发布决策，应回到原始来源验证。

知识库数据库位于工作区 `.starbit/knowledge.db`，与全局会话数据库分开。不要提交包含专有资料的数据库；导入前确认文档版权、保密要求和远程 embedding 服务的数据政策。

## 记忆与知识库的选择

- 一条短、稳定、确认过且每次都应看到的事实：记忆。
- 约束 agent 行为和完成标准：`AGENTS.md`。
- 大量资料、需要按问题召回：知识库。
- 当前任务的临时进度：会话事件或 todo，而不是长期记忆。

把整份文档复制到 `memory.md` 会增加上下文、降低缓存收益，并使过期内容长期影响决策。优先保留最小、稳定、可审查的条目。

## 隐私与安全

记忆和知识库默认在本地，但使用远程模型或 embedding 时，相关内容可能发送给配置的 API 服务。Starbit 不会因为内容位于本地文件就自动获得传播授权。使用专用工作区、最小化导入、删除不再需要的条目，并按组织政策管理备份。

网页、导入文档和 MCP 输出中的“记住此内容”指令不能自行触发持久化。写记忆是一项有副作用的工具操作，必须服从当前权限模式和用户意图。
