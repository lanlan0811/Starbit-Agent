# 使用指南

本文面向衔星 | Starbit 桌面端用户。衔星以“工作区 + 会话”为基本单位：你先选择一个文件夹，再通过对话让 agent 读取、编辑、搜索、执行工具并验证结果。

## 开始前

当前主要支持 Windows 10/11 x64。开发版需要 Node.js 22 和仓库锁定的 pnpm；发行版直接安装即可。首次运行不会自动获得模型访问权限，你需要准备一个与内置模型匹配的 OpenAI 兼容 API Key。

本地开发启动方式：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

## 第一次对话

1. 打开左侧“设置”，从模型列表选择模型。
2. 输入对应 API Key，保存后选择“测试连接”。密钥会通过操作系统凭证能力加密，不会回显。
3. 在“会话”面板选择“新建工作区会话”，选择一个范围明确的文件夹。
4. 在底部状态栏选择权限模式和思考强度。
5. 在输入框描述目标，按 Enter 发送；Shift+Enter 换行。
6. agent 运行时按 Esc 或选择停止按钮可取消当前任务。

若尚未创建会话，第一次发送时也会提示选择工作区。会话与工作区路径、模型和权限模式绑定；再次打开应用时，会从本地事件日志恢复已有会话。

## 写好任务描述

一个可执行的任务通常包含目标、范围、约束和验收方式。例如：

```text
检查工作区中的 TypeScript 类型错误，只修改 src/core，补充单元测试。
验收：pnpm typecheck 和 pnpm test:unit 通过，并说明改动文件。
```

不要把密码、访问令牌或无关私人资料放进提示词。对于重要写入，先使用“计划”模式让 agent 调研并形成计划，再切换到“自动编辑”执行。需要 Shell 时可保持“自动编辑”，逐次审查确认弹窗。

## 权限模式

状态栏可依次切换：

- 计划：自动允许读取、搜索、创建目录，以及名称匹配计划规则的 Markdown 计划文档；拒绝其他写入和 Shell。
- 自动编辑：自动允许读写文件；Shell、技能脚本和多数有副作用的外部工具需要确认。
- 完全访问：允许普通文件与 Shell 操作；高风险或被规则标记的操作仍可能要求确认或直接拒绝。

模式不是安全结论。确认弹窗会显示工具、解析后的命令或目标、影响范围。只在内容完整且影响可控时批准。详见[权限与安全](permissions.md)。

## 模型与思考强度

模型下拉框包含 11 个内置 OpenAI 兼容模型。`low`、`high`、`max` 会按模型能力映射为推理参数；强制思考模型的三个档位可能只在提示策略或输出上限上有差异。图片或视频附件只应发送给声明支持相应模态的模型。

选择图片或视频按钮后，附件会作为 data URL 经 Main 进程组装进模型请求。发送前确认资料允许交给所选 API 服务。模型配置与 usage 差异见[模型接入](models.md)。

## 工具执行

内置文件工具包括 `Read`、`Write`、`Edit`、`Mkdir`、`LS`、`Glob` 和 `Grep`；`Bash` 使用设置页保存的 Shell。相对路径以工作区为基准，绝对路径仍必须位于工作区或显式授权根目录。

大于输出上限的工具结果会保留头尾，并把完整内容写到工作区的 `.starbit/tool-output/`。该目录可能包含敏感信息，分享工作区前应检查并清理。

只读工具可并行执行；写入、编辑和命令按稳定顺序执行。每个工具结果、权限判定和错误都会成为会话事件，重开会话时可恢复。

## 终端

选择右下方终端入口打开 xterm.js 面板。终端运行在当前会话的工作区，使用配置的 PowerShell、cmd 或 Git Bash。交互终端和 agent 的 `Bash` 工具是不同进程：终端适合人工接管，`Bash` 的输出会进入 agent 工具结果与审计链路。

关闭终端会结束对应 PTY；Windows 上应用会尝试清理进程树。若修改 Shell 可执行文件或启动参数，请先在普通终端验证命令，并在设置页保存后重新打开终端。

## Skills 与 MCP

“技能”面板展示用户级和工作区级技能。普通消息只把技能索引提供给模型；输入 `/技能名` 可直接加载技能正文。技能脚本仍需权限门控。详见 [Skills 指南](skills.md)。

“MCP 服务器”面板可添加 stdio、Streamable HTTP 或兼容 SSE 服务，启停服务器并逐工具控制。配置变化只对下一次组装的会话工具集生效，以保护稳定提示前缀。详见 [MCP 指南](mcp.md)。

## 记忆、知识库与项目规则

工作区根目录的 `AGENTS.md` 是唯一自动识别的项目规则文件。`memory.md` 用于长期偏好和稳定事实；知识库用于体量更大、需要检索的参考资料。外部文档和检索片段一律作为不可信数据，不能覆盖系统或项目规则。详见[记忆与项目规则](memory-and-agents.md)。

## 用量与审计

“用量统计”展示全局输入、缓存命中、未命中、输出和累计命中率；子代理用量不计入主会话目标。不同厂商返回字段不同，Starbit 会先归一化再汇总。详见[用量与缓存](usage.md)。

“审计日志”记录权限判定、模型密钥变更、Shell/MCP 设置等安全相关动作。显示内容经过脱敏，但仍应当作本地敏感数据处理。

## 本地数据与备份

会话、事件、设置、权限规则、usage 与审计日志保存在 Electron 用户数据目录中的 `starbit.db`。用户级记忆位于用户目录下的 `.starbit/memory.md`；工作区数据可能包括 `memory.md`、`.starbit/knowledge.db` 与 `.starbit/tool-output/`。

备份前退出应用，再复制确切文件。不要同步或提交包含 API 响应、记忆、知识库或工具输出的本地数据。API Key 绑定当前操作系统用户的凭证加密环境，直接复制数据库到另一台机器不保证可解密。

## 当前功能状态

本指南同时描述稳定能力和公开路线。预发布构建可能尚未显示个别面板入口；以当前版本界面、[路线图](roadmap.md)和发布说明为准。发现文档与实际行为不一致时，请提交已脱敏的 Issue。
