# Issue 反馈

## 1. Issue 类型

请选择最符合的一项：

- [ ] Bug 报告 —— 行为不符合预期、崩溃或与文档描述相矛盾
- [ ] 功能建议 —— 提出一个当前不存在的全新能力或工作流
- [ ] 改进建议 —— 对已有行为、性能或体验的优化
- [ ] 文档问题 —— 文档、内置 prompts 或错误提示缺失、有误或存在误导
- [ ] 提问 / 咨询 —— 需要帮助理解或使用本项目

> 安全漏洞请勿通过公开 Issue 上报，请遵循 SECURITY.md 中描述的披露流程。
